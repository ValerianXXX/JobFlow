# Document QA

Tailor an editable DOCX master only by copying it and patching documented text slots. Preserve page geometry, styles, table grids, numbering, headers/footers, relationships, hyperlinks and unexplained package parts. Never overwrite the master. A PDF master may be stored but is not an editable format-preservation source.

Only current approved Claims may enter Summary, Experience, Projects, Skills, Education, Cover Letter or application narrative. Real mode removes personal metadata and forbids synthetic, JobOps, evidence-gated, `UNKNOWN`, placeholders and `secure-ref` markers.

Before `MATERIALS_VALIDATED` require: traceable Claims and responsibility boundaries; fact/number/date checks; ATS text; keyword review; enforced page limit; DOCX/PDF token consistency; placeholder scan; valid links and hashes; real render PNGs; and a structured visual record with render time, review time, reviewer type, every page hash, result and reason. A caller-supplied `PASS` string is invalid evidence.

Inspect every final page for clipping, overlap, broken tables/bullets, font substitution, blank pages, orphan lines, unreadable size and overflow. The automated blank/corruption probe is supporting evidence only; release also requires an actual visual reviewer.
