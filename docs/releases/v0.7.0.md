# JobFlow v0.7.0 - Early Source Release

## Highlights

- Deeper local review and synthetic browser coverage for company-direct, Greenhouse, Lever, Workday, Ashby, and SmartRecruiters routes.
- Safer multi-page prefill, approved attachments, field reconciliation, and non-final navigation.
- Stronger Windows installation, activation, rollback, recovery, and release verification.

## Browser Companion

Version **0.9.2** is publicly available on [Chrome Web Store](https://chromewebstore.google.com/detail/pgcnlkfakkacphkdojdbphccjnbbefic) and [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/cebejbohadiofomfiplljnpdefjeiccp), independently verified on September 5, 2026. This closes the public store-version requirement, not clean-profile installation or end-to-end acceptance.

The latest stable desktop, v0.6.0, strictly requires Browser Companion 0.9.1 and cannot pair with the store's 0.9.2 update. This v0.7.0 source targets 0.9.2, but a matching signed stable desktop update is still pending. Do not bypass version validation or repeatedly reinstall the extension to resolve an older desktop's mismatch.

## Still a prerelease

- Hosted Windows CI has outstanding failures; corrective work is being verified separately on `main`.
- Protected publisher attestation, signed complete-runtime assets, and clean-Windows acceptance remain outstanding. The bootstrap installer will not activate an unsigned source-only download.
- No signed update manifest or attested Windows runtime is attached. This is not an update-capable stable release.
- Historical public contributor email metadata still conflicts with the automated noreply-only candidate policy; published history has not been rewritten.

Final application Submit remains user-only. No credential handling, account creation, CAPTCHA/MFA/OTP bypass, or automatic retries of unknown outcomes. Synthetic tests do not establish universal live-site compatibility.
